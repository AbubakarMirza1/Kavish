# EcoDash

**EcoDash** is a sustainability dashboard developed as part of our final year project ("Kaavish") at Habib University. It enables organizations to monitor and manage carbon footprints and waste production, supporting compliance with standards like the GHG Protocol, ISO 14064, and TCFD.

## Overview

- **Carbon Footprint Tracking**: Calculates GHG emissions (Scope 1, 2, and 3) with reduction recommendations.
- **Waste Management**: Offers waste categorization and reuse suggestions.
- **Data Visualization**: Real-time charts and graphs for intuitive analysis.
- **Automated Reporting**: Compliance-ready reports aligned with international standards.
- **User Roles**: Role-based access control for secure data handling.
